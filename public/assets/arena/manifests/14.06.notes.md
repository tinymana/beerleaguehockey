# Batch 14.06 — Arena scoreboard
Load individual PNGs or atlas rectangles, never both. Use nearest-neighbor scaling. Mount outside playable ice. Draw live score, clock, period and penalty timers in manifest dynamicFields using a compact pixel font; penalty fields need 3x5 glyphs. Select goal state on confirmed goal, intermission on period break, final on match completion; otherwise normal. Restore normal after goal presentation. Do not modify scoring, clock or simulation logic. All panels are static; state changes are engine-driven. Verify legibility and placement in Arena Asset Lab. Preview is not a runtime asset.
