# Batch 09.05 — Blue line tiles
Use the 32×8 atlas with 8×8 tiles, zero spacing and margin. Repeat index 0 horizontally across the playable ice at both existing blue-line coordinates. Indices 1–3 are optional alternate styles; use one consistent variant per rink. Clip to ice bounds. Render above ice and below players. Use nearest-neighbor filtering and integer scaling. Preserve existing collision and offside geometry. Four-pixel thickness is provisional and matches Batch 09.04. Preview is reference only. Validate in game.
