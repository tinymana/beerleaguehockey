# Batch 09.03 — Overhead light reflections
Load the 32x32 atlas as 8x8 frames, row-major, zero-based. Use sparse reflection overlays above base ice and scratches, below rink markings and actors. Use nearest-neighbor filtering, ADD blend and start at alpha 0.45. Keep reflections fixed in world space. Do not alter rink geometry or physics. Preview is not a runtime asset. Test brightness and seams in game.
